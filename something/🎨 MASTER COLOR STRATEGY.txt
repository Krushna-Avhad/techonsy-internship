🎯 HOW TO APPLY CITY COLORS (DESIGN RULES)
✅ Use city primary color in:
Hero background
City title
Buttons
✅ Use secondary color in:
Icons
Section borders
Hover effects
✅ Use highlight sparingly:
Cards
Text background
Dividers
🚫 Never mix two city palettes on one page
🧩 BONUS: CSS VARIABLES (BEST PRACTICE 💡)
Later we’ll do:

:root {
  --brand-primary: #1C1F4A;
  --brand-gold: #C9A24D;
}

And city-wise:

.mumbai {
  --city-primary: #0B1C2D;
}
